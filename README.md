# Practicas de PHP
En este repositorio se estará documentando y llevando un seguimiento de las practicas y actividades dadas en el curso de desarrollo web 
## objetivos
- Practicar la sintaxis básica de PHP (variables, condicionales, validaciones).
- Combinar HTML, CSS y PHP en formularios funcionales.
- Aprender a validar datos ingresados por el usuario, tanto en el cliente (HTML) como en el servidor (PHP).
- Ir subiendo cada ejercicio del curso a medida que se completa, como registro de aprendizaje.
